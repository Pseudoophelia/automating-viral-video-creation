# Midjourney stills guide

The Midjourney step's only job: turn each approved storyboard frame into the
finished still that the video generation starts from. Shots were planned in
the Veo storyboard; voices live in the ElevenLabs script. Do not replan the
episode here.

## Style plus reference, short prompt

- Every frame is generated with the director's saved style from her
  Midjourney Style tab (the style reference), and the storyboard frame
  itself as the reference image.
- The style and the frame carry the look, so the prompt stays short. A few
  plain words naming the subject and the action; nothing else. If a prompt
  is growing long, the references are wrong, not the words.
- Be simple on prompts. With good references, extra direction only confuses
  the model.

## References

- Use the director's original reference images, never re-generations of
  them. Re-referencing a generated image degrades it like a xerox.
- For character continuity, upload a cutout of the face only. Whole images
  confuse the reference system.
- Composition is decided in Midjourney. Effects (outlines, cutout looks,
  text) are applied in post, standardized across frames. Do not burn
  generations trying to make Midjourney do post work.

## Credits and approval

- Plan every composition before generating. Credits are limited.
- Generate ONE frame first and show it to the director. The look is
  approved on that frame before any more frames are made.
- Ask before every extra round beyond the approved batch.
- By five generations on a frame, stop and run with what there is. Salvage
  and post work beat more spend.
- Check anatomy before showing anything: necks, heads on shoulders, hands.
  If it looks wrong, it is wrong.

## Output

- One approved still per storyboard shot ID, named by shot ID. The still
  feeds the video tool as the shot's starting image; the Veo storyboard's
  simple direction animates it.
